# Test fixtures

**`portrait-public-domain.jpg`** — official White House photographic portrait of President Barack
Obama, a U.S. federal government work and therefore in the public domain
([source](https://storage.googleapis.com/mediapipe-assets/portrait.jpg), also used as a standard
test asset in Google's own MediaPipe documentation/samples). Used only by
[`../../test-image.html`](../../test-image.html), a diagnostic page that runs the self-hosted Face
Landmarker against a real, unambiguous face to verify landmark/blendshape/ROI extraction without
needing a live webcam — see PLAN.md §10 Phase 0. Not used anywhere in the shipped product UI.
